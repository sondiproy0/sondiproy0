# Cybersecurity Portfolio AI Instructions

You are working on a production-quality cybersecurity portfolio.

## Project Goal

Build a premium portfolio that looks comparable to:

- Linear
- Stripe
- Cloudflare
- CrowdStrike
- Vercel

This is NOT a resume website.

It should feel like the landing page of a cybersecurity engineer.

---

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Framer Motion

---

## Design Principles

Minimal.

Premium.

Professional.

Dark theme.

No unnecessary gradients.

No oversized cards.

No generic templates.

Reduce scrolling.

Prioritize whitespace.

Strong typography.

Every section should communicate expertise.

---

## Code Rules

Before modifying code

- inspect existing components
- understand architecture
- reuse existing components
- never duplicate components
- never rewrite unrelated files

Always

- keep TypeScript strict
- remove dead code
- optimize imports
- optimize animations
- optimize performance

---

## Animations

Use Framer Motion.

Animations should be subtle.

Avoid flashy effects.

---

## UI Rules

Avoid giant cards.

Prefer compact reusable components.

Every component should have one responsibility.

Maintain consistent spacing.

Follow existing design tokens.

---

## Workflow

For every task

1. Analyze
2. Explain
3. Identify files
4. Implement
5. Refactor
6. Review

Never skip analysis.

Never modify unrelated files.

Always explain architectural changes first.
